חיבור ה-iPhone ל-LOCKFLOW

קיצור אחד באפליקציית קיצורים אוסף את היומן, התזכורות ונתוני הבריאות של היום, ופותח את LOCKFLOW עם הנתונים. הוא רץ לבד ב-9:00 וב-20:00, ואפשר לפתוח אותו גם מאייקון במסך הבית.

פרטיות

הנתונים עוברים בחלק של הכתובת שאחרי הסימן #. הדפדפן אף פעם לא שולח את החלק הזה לשרת. הם נשמרים רק ב-Safari בטלפון שלך.

1. יצירת הקיצור

פותחים את קיצורים ← + ← קוראים לקיצור LOCKFLOW. מוסיפים את הפעולות לפי הסדר. אם הטלפון בעברית ושם הפעולה לא נמצא, מחפשים לפי המילה שבסוגריים.

  1. Find Calendar Events (יומן). מסנן: Start Date · is today. מיון: Start Date · Oldest First.
  2. Repeat with Each (חזרה) על האירועים. בתוך הלולאה מוסיפים Text (טקסט) ובונים את השורה:
    E|Start Date · HH:mm|End Date · HH:mm|Title

    מקלידים E|, מכניסים את המשתנה Repeat Item, לוחצים עליו ובוחרים Start Date. בתבנית התאריך בוחרים Custom וכותבים HH:mm. כך גם לשאר.

  3. אחרי End Repeat: Combine Text (שילוב) על Repeat Results, עם New Lines. ואז Set Variable (משתנה) בשם Events.
  4. Find Reminders (תזכורות). מסננים: Is Completed · is false, Due Date · is today.
  5. Repeat with Each על התזכורות. בפנים, Text:
    R|List|Title

    אחרי End Repeat: Combine Text עם New Lines, ואז Set Variable בשם Reminders.

  6. Find Health Samples (בריאות). סוג: Steps, מסנן Start Date · is today. אחריה Calculate Statistics (סטטיסטיקה) ← Sum, ואז Set Variable בשם Steps.
  7. אותו דבר עם הסוג Walking + Running Distance, לתוך משתנה בשם KM.
  8. רק אם יש לך Apple Watch: אותו דבר עם Exercise Minutes, לתוך משתנה בשם Exercise. בלי שעון מדלגים, ובשלב הבא משמיטים את השורה שמתחילה ב-M.
  9. Text. זה הטקסט הסופי, כל פריט בשורה משלו:
    T|Current Date · yyyy-MM-dd S|Steps K|KM M|Exercise Events Reminders
  10. URL Encode (קידוד) על הטקסט מהשלב הקודם.
  11. Text: מדביקים את הכתובת הזו, ובסופה מכניסים את המשתנה URL Encoded Text:
    …
  12. Open URLs (פתיחת כתובות) על הטקסט מהשלב הקודם.

2. הרצה ראשונה

מריצים את הקיצור פעם אחת ידנית ומאשרים כל בקשת הרשאה (יומן, תזכורות, בריאות, פתיחת האתר). כשיש אפשרות, בוחרים אפשר תמיד. בלי האישורים האלה האוטומציה לא תוכל לרוץ לבד.

אם הכל עבד, נפתח Safari עם LOCKFLOW, ולמעלה מופיעה הודעה כמו Synced · 3 events · 2 reminders.

3. אייקון במסך הבית

לחיצה ארוכה על התמונה ← שמור בתמונות.

בקיצורים: לחיצה ארוכה על LOCKFLOW ← שיתוף ← הוסף למסך הבית. לוחצים על האייקון הקטן ← בוחרים את התמונה ששמרת.

חשוב: לא מוסיפים את האתר עצמו מ-Safari למסך הבית. האייקון של הקיצור הוא הדרך הנכונה, כי כל פתיחה ממנו גם מסנכרנת.

4. פתיחה אוטומטית ב-9:00 וב-20:00

קיצורים ← אוטומציה ← + ← שעה ביום ← 9:00, כל יום ← הפעל מיד ← בוחרים את הקיצור LOCKFLOW. חוזרים על אותו דבר ל-20:00.

LOCKFLOW עוברת לבד למצב סגירת היום משעה 16:00. אפשר לשנות את זה בהגדרות.

אם הטלפון נעול באותו רגע, ייתכן שהדף ייפתח רק אחרי שתפתח את הנעילה.

5. שהכרטיסיות לא יצטברו

כל הרצה של הקיצור פותחת כרטיסייה חדשה ב-Safari. בהגדרות ← אפליקציות ← Safari ← סגירת כרטיסיות ← אחרי יום.

אם משהו לא עובד

בהגדרות של LOCKFLOW (Settings & iPhone sync) רואים מתי היה הסנכרון האחרון ומה הגיע בו.

כדי לראות מה הקיצור מייצר: מוסיפים בסופו Copy to Clipboard על הטקסט משלב 9, ומדביקים ב-Paste sync text בהגדרות.
